# FreeDom Launcher — функции версии 1.0.0

Реализовано: боковая навигация и тёмная/светлая/системная темы с акцентным цветом; сборки (создание, переименование, дублирование, удаление с подтверждением, активная сборка, Java и ОЗУ, изолированные папки); Vanilla и Fabric; установка и запуск через CmlLib.Core с прогрессом, отменой, логом игры; вход Microsoft (Device Code Flow, DPAPI); каталог Modrinth (моды, сборки, ресурс-паки, шейдеры, датапаки, плагины), страница проекта; установка/отключение/включение/удаление/обновление модов с зависимостями и проверкой SHA-1/SHA-512; умный поиск; настройки и логирование; тесты xUnit.

Запланировано: Forge, NeoForge, Quilt; Ely.by; установка .mrpack; казахская раскладка в умном поиске.
