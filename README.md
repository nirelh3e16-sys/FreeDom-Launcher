# FreeDom Launcher

Свободный лаунчер для Minecraft: Java Edition с умными пресетами модов, поддержкой Steam и глубокой настройкой внешнего вида.

> **Статус: ранняя разработка.** Проект находится на стадии проектирования, большая часть функций из списка ниже ещё не реализована. Актуальное состояние смотрите в разделе [Дорожная карта](#дорожная-карта).

## Главные идеи

- **Пресеты модов.** Выберите моды из одной сборки (Sodium, Lithium, FerriteCore и т. д.), сохраните как пресет, и лаунчер предложит добавить их в каждую новую сборку. При смене версии игры лаунчер сам проверит, каких модов ещё нет.
- **Сборки как отдельные игры в Steam.** Запуск любой сборки через аргументы командной строки, генерация `.bat` / `.sh`, оверлей и статус «в игре».
- **Умный поиск.** Исправляет неверную раскладку (`ыщвшгь` → `sodium`) и понимает транслитерацию (`содиум` → `sodium`).
- **Свои моды для чата.** Исправление раскладки в командах (`.пшму` → `/give`) и T9-подсказки.
- **Любые аккаунты.** Лицензия Microsoft (лаунчер не видит ваш пароль), Ely.by и игра по нику.
- **Полная кастомизация.** Свои цвета, градиенты, шрифты и ресурспаки для интерфейса лаунчера.

## Возможности

### Запуск и настройки
- Аргументы Java, установка Java, выделение ОЗУ
- Умная рекомендация ОЗУ с учётом объёма памяти ПК, числа модов и версии игры
- Мастер первого запуска

### Аккаунты и скины
- Лицензионный аккаунт через вход Microsoft (пароль лаунчеру не передаётся)
- Ely.by
- Игра по нику (офлайн-режим; не работает на серверах с `online-mode=true`)
- Отображение скинов для каждого типа аккаунта

### Сборки и контент
- Установка модов, карт, ресурспаков, датапаков и шейдеров с **Modrinth** и **CurseForge** прямо из лаунчера
- Автоматическая проверка зависимостей с вопросом перед установкой
- Пресеты модов с импортом и экспортом
- Загрузчики: Fabric, Forge, NeoForge, Quilt
- Отключение модов переключателем, поиск проблемного мода, заметки к модам
- Импорт и экспорт сборок (`.mrpack`, zip)

### Серверы
- Пинг сервера по IP: версия, онлайн, список игроков, описание
- Избранные серверы с группами и заметками

### Галерея
- Скриншоты из всех сборок
- Записи Flashback и ReplayMod, записи из Steam

### Steam
- Добавление лаунчера и отдельных сборок как сторонних игр
- Запуск сборки или сервера одной кнопкой:
  ```
  FreeDomLauncher.exe --launch <id-сборки>
  FreeDomLauncher.exe --launch <id-сборки> --server play.example.com
  ```
- Приглашения на сервер с IP, версией и информацией о белом списке

### Диагностика
- Понятный разбор крашей
- Загрузка лога на mclo.gs одной кнопкой
- Автоматические бэкапы миров

### Кастомизация
- Тема: светлая, тёмная или системная, любые RGB-цвета фона
- Главный цвет и градиенты из 2-4 цветов
- Свой шрифт `.ttf`
- Ресурспаки для интерфейса лаунчера
- Настройка расположения элементов

## Технологии

- **C#** и **.NET 10**
- **Avalonia UI** для кроссплатформенного интерфейса
- **CmlLib.Core** для запуска Minecraft
- **Steamworks.NET** для интеграции со Steam
- Моды для чата: **Java / Kotlin**

> Список технологий может измениться по ходу разработки.

## Сборка из исходников

Понадобится [.NET SDK](https://dotnet.microsoft.com/download) 10.0 или новее.

```bash
git clone https://github.com/nirelh3e16-sys/FreeDom-Launcher.git
cd FreeDom-Launcher
dotnet run
```

Если решение содержит несколько проектов, запускайте проект лаунчера явно:

```bash
dotnet run --project <путь-к-проекту>
```
