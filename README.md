# FreeDom Launcher 1.0.0

Лаунчер Minecraft Java Edition на C# / .NET 10 / Avalonia UI. Windows 10/11 x64.
Сборки Vanilla и Fabric, встроенный каталог Modrinth, установка модов с зависимостями, умный поиск.

## Как получить готовый .exe (без установки .NET)

**Через GitHub (рекомендуется):**
1. Загрузите содержимое этой папки в репозиторий (ветка `main`).
2. Откройте вкладку **Actions → Build FreeDom Launcher** (запускается сам после push; можно нажать *Run workflow*).
3. Когда сборка зелёная, откройте её и скачайте артефакт **FreeDomLauncher-1.0.0-win-x64** (zip).
4. Распакуйте и запустите `FreeDomLauncher.exe`.

Чтобы получить файл на странице Releases, создайте тег: `git tag v1.0.0 && git push origin v1.0.0`.

**Локально:** установите [.NET SDK 10](https://dotnet.microsoft.com/download), запустите `build.bat`. Результат: `publish\FreeDomLauncher.exe`.
Для разработки: `dotnet run --project FreeDomLauncher.App`. Тесты: `dotnet test`.

## Первый запуск

1. **Сборки → Новая сборка**: имя, версия Minecraft, загрузчик (Vanilla/Fabric), ОЗУ.
2. **Аккаунты → Войти через Microsoft** (нужен Client ID, см. ниже).
3. **Главная → Играть**. При первом запуске скачиваются клиент, библиотеки, ассеты и Java (если путь к Java не указан).
4. **Моды и проекты**: найдите мод, откройте страницу, нажмите «Установить». Лаунчер подберёт версию под Minecraft и загрузчик активной сборки, покажет зависимости и попросит подтверждение.

Данные хранятся в `%APPDATA%\FreeDomLauncher`: `settings.json`, `profiles.json`, `accounts.json`, `secrets\` (токены, шифрованы DPAPI), `instances\` (сборки), `minecraft\` (общие библиотеки/ассеты/Java), `logs\` (лог лаунчера и `logs\games\` — логи игры), `cache\`.

## Авторизация Microsoft (обязательная настройка разработчика)

Лаунчер использует официальный Device Code Flow: пароль в окне лаунчера не вводится, вход подтверждается в браузере. Для этого нужно **собственное приложение Azure**:

1. Откройте [portal.azure.com](https://portal.azure.com) → **Microsoft Entra ID → App registrations → New registration**.
2. Имя: `FreeDom Launcher`. Тип аккаунтов: **Personal Microsoft accounts only** (или «any organizational directory and personal»). Redirect URI не нужен.
3. **Authentication → Advanced settings → Allow public client flows = Yes**, сохраните.
4. Скопируйте **Application (client) ID** и вставьте в лаунчере: **Настройки → Вход Microsoft**.
5. **Одобрение Mojang.** Новые приложения не допускаются к Minecraft API автоматически: на шаге `login_with_xbox` будет ошибка 403 «приложение не одобрено». Нужно подать заявку на одобрение приложения (по документации сообщества — форма https://aka.ms/AppRegistrationForm; уточните актуальную процедуру на minecraft.wiki → «Microsoft authentication»). Пока одобрения нет, вход не сработает. Это ограничение Mojang, лаунчер его не обходит и вход не имитирует.

Токены хранятся только в зашифрованном виде (Windows DPAPI, привязка к пользователю Windows) и не пишутся в логи. Режим «ник без лицензии» в 1.0.0 не реализован намеренно. Архитектура (`IAuthProvider`) готова для добавления Ely.by.

## Умный поиск

- **Раскладка:** `ыщвшгь` → «Возможно, вы имели в виду Sodium?» (RU и UK; казахская раскладка использует тот же базовый набор букв, специфичные казахские клавиши пока не сопоставлены).
- **Транслитерация:** `содиум`, `литиум`, `ферритекор`.
- **Опечатки:** `sodum`, `lithum` (расстояние Дамерау — Левенштейна + словарь популярных проектов, обновляется с Modrinth раз в 7 дней).
- **Контекст:** `fps`, `оптимизация` → категория optimization; `миникарта` → minimap.
- Подсказка показывается только при достаточной уверенности и после проверки реальным поиском. Исходный запрос всегда доступен кнопкой. Debounce 350 мс, предыдущий запрос отменяется.

## Устранение проблем

| Проблема | Решение |
|---|---|
| «Не указан Client ID» | Настройки → Вход Microsoft (см. выше) |
| Ошибка 403 при входе | Приложение Azure не одобрено Mojang (шаг 5) |
| «Allow public client flows» | Включите в Azure → Authentication |
| Нет Minecraft на аккаунте | Нужна лицензия Java Edition |
| Java не найдена / не подходит | Очистите поле Java — лаунчер скачает нужную сам |
| Игра закрылась сразу | Главная → «Открыть лог» (`logs\games\...`) |
| Нет соединения с Modrinth | Проверьте интернет/VPN; при 429 подождите минуту |
| Мод не устанавливается | Проверьте, что у сборки Fabric (для Vanilla моды недоступны) и версия мода есть для вашей версии Minecraft |
| Лог лаунчера | `%APPDATA%\FreeDomLauncher\logs` |

## Структура

```
FreeDomLauncher.Core            модели, интерфейсы, чистая логика (фильтр версий, зависимости, умный поиск)
FreeDomLauncher.Infrastructure  Modrinth API, запуск (CmlLib.Core), хранилище JSON, DPAPI, Microsoft OAuth, логи
FreeDomLauncher.App             Avalonia UI (MVVM, CommunityToolkit.Mvvm, DI)
FreeDomLauncher.Tests           xUnit-тесты (без сети и без аккаунта)
```

## Известные ограничения 1.0.0

- Загрузчики Forge / NeoForge / Quilt: заложены в архитектуре, установка не реализована.
- Сборки модов (.mrpack), карты и датапаки: только просмотр (на Modrinth нет типа «карты», показаны датапаки). Плагины: только просмотр с предупреждением.
- Установка ресурс-паков и шейдеров поддерживается (папки `resourcepacks`, `shaderpacks`), зависимости обрабатываются только для модов.
- Скачивание файлов игры идёт через CmlLib.Core; отмена на этом этапе срабатывает после завершения текущей операции библиотеки.
- Полная проверка на живой установке Minecraft требует аккаунта и одобренного Azure-приложения.
